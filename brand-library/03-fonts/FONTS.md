# WAG · Шрифты

Три фирменные гарнитуры (все — Google Fonts, лицензия **SIL Open Font License 1.1**:
свободное использование в любых материалах компании, включая коммерческие).

## Установка

Выделить все TTF в подпапках → ПКМ → **Установить для всех пользователей**.
После установки перезапустить InDesign/Illustrator.

## Роли

| Гарнитура | Роль | Начертания в комплекте | Кириллица |
|---|---|---|---|
| **Space Grotesk** | Заголовки, кнопки, акциденция | 300 / 400 / 500 / 600 / 700 | ❌ НЕТ |
| **Onest** | Основной текст, подписи | 300 / 400 / 500 / 600 / 700 / 800 | ✅ да |
| **Outfit** | Display: крупные цифры, обложки | 300 / 400 / 500 / 600 / 700 | ❌ НЕТ |

## ⚠️ Главное правило: кириллица

У Space Grotesk и Outfit **нет кириллических глифов**. На сайте браузер молча
подставляет Onest — **InDesign этого не сделает** (покажет розовые плашки missing glyphs).

Правило для вёрстки:

- Русский заголовок → **Onest SemiBold/Bold** (это фирменная замена, не ошибка)
- Латинские заголовки, цифры, «WEST ARLAN GROUP» → Space Grotesk / Outfit
- Смешанная строка → вся строка в Onest

## Типовые пары (из брошюры)

| Элемент | Шрифт | Кегль / трекинг |
|---|---|---|
| Display-цифры (136, 16 лет) | Outfit / Space Grotesk 700 | 44 pt |
| H1 страницы | Space Grotesk 700 (RU → Onest 700) | 28 pt, -0.5 % |
| H2 секции | Space Grotesk 700 (RU → Onest 700) | 16 pt |
| Основной текст | Onest 400 | 9,5 pt / 14 pt интерлиньяж |
| Eyebrow / служебные надписи | Space Grotesk 600, CAPS | 7,5 pt, +6 % трекинг |

Полная шкала → `../07-styles/STYLE-GUIDE.md`.

## Примечание

В `public/fonts/` репозитория лежат также Inter, Roboto, Noto Sans, JetBrains Mono —
это **технические** шрифты старых движков и og-image, к фирменному стилю они
не относятся. Не использовать в макетах.
