# WAG · Цвета

Две палитры: **Web** (экран, тёмная тема сайта) и **Print** (полиграфия, крем/золото
из фирменной брошюры). Для КП, визиток и инфолистов по умолчанию используйте **Print**;
Web — для презентаций на экране и digital-материалов.

## Файлы

| Файл | Что это | Как использовать |
|---|---|---|
| `wag-web.ase` | Экранная палитра, RGB | AI/ID: панель Swatches → меню → **Load/Import Swatches…** |
| `wag-print.ase` | Печатная палитра, RGB | то же |
| `wag-print-cmyk.ase` | Печатная палитра, CMYK | для документов, которые уйдут в типографию |
| `palette-web.svg` / `palette-print.svg` | Листы с квадратами цветов | открыть в AI → брать цвет **пипеткой** |
| `palette-sheet.pdf` | Оба листа + градиенты одним PDF (вектор) | можно `File → Place…` в InDesign |
| `gradients.svg` | Все фирменные градиенты с точными стопами | пипетка по стопам / референс |

Градиенты в свотчи Illustrator собираются автоматически — запустите
`../scripts/setup-illustrator.jsx` (File → Scripts → Other Script…).

## Правила использования

1. **Золото — дефицитный ресурс.** Один решающий золотой акцент на страницу
   (заголовок, цифра, линия). Служебные элементы — `meta`/`muted`, не золото.
2. **Экранное золото ≠ печатное.** На экране `#D4A843`, в печати `#C9941F`
   (яркое экранное золото на бумаге выглядит грязно-жёлтым).
3. **Полупрозрачные цвета** (стекло, линии) в ASE не живут — задавайте
   через Opacity/Tint: линия-золото на тёмном = gold @ 45%,
   разделитель на кремовом = ink-2 @ 12–18%, разделитель на тёмном = text-primary @ 8–12%.
4. **CMYK — ориентир.** Перед тиражом прогнать через профиль типографии
   (по умолчанию Coated FOGRA39). Золото в CMYK глохнет — для статусных
   носителей (визитки руководства) рассмотреть Pantone 7555 C или металлик 871 C.
5. **Никогда:** золото на teal, teal на золоте, чистый чёрный `#000` как фон
   (фирменный тёмный — `#04060C`).
