# WAG · Фото и партнёрские логотипы

## Логотипы партнёров (`partners/`)

16 логотипов заказчиков/партнёров — копия рабочего набора сайта (`public/partners/`).
PNG/JPG, растровые. Правила размещения в КП и брошюрах:

- Сетка: одинаковая **высота** ряда (не ширина), выравнивание по оптическому центру.
- На тёмном фоне: белая подложка-карточка `cream-card #F8EFE0` со скруглением 6–10 px
  или логотип в белой отрисовке (если предоставлен).
- Не растягивать, не перекрашивать, не обрезать.
- Мелкий кегль подписи: «Нам доверяют» / «Наши заказчики».

## Обработка фотографий проектов

Фирменный приём сайта — фото под тёмным градиентом, поверх — текст/цифры.

**Рецепт оверлея (сверху вниз):**

1. Фото — desaturation −10…−20 %, лёгкий тёплый тон.
2. Градиент: `#04060C` 85 % непрозрачности внизу → 25 % вверху (linear, 180°).
3. При тексте слева: дополнительный горизонтальный градиент
   `#04060C` 70 % слева → 0 % к центру.
4. Текст только в зонах с непрозрачностью фона ≥ 60 %.

**В печати (кремовые страницы):** фото в карточке со скруглением 2–3 мм,
тонкая рамка `ink-2` 12 % непрозрачности, БЕЗ тёмного оверлея. Подпись под фото
7,5 pt `meta`.

**Запрещено:** цветные фильтры (синие/зелёные тонировки), жёсткие тени,
рамки золотом вокруг фото (золото — для акцентов, не для обводок фото).
